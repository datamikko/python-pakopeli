# Lukittu laboratorio – Python-pakopeli

Selaimessa pelattava pakopeli Pythonin perusteiden opetteluun. Kymmenen huonetta, jokaisessa lyhyt oppitunti ja kolme lukkoa. Oikeat vastaukset avaavat oven ja antavat kirjaimen, joista lopussa kootaan ulko-oven koodi.

## Aiheet

1. `print()` ja laskutoimitukset
2. Muuttujat
3. Datatyypit
4. Listat ja sanakirjat
5. Funktioiden kutsuminen
6. Kirjastot ja `import`
7. Vertailut ja ehdot
8. `if` / `elif` / `else` ja sisennys
9. `for`-silmukka
10. Oman funktion tekeminen

## Käyttö

Avaa `index.html` selaimessa. Ei asennusta, ei riippuvuuksia – yksi HTML-tiedosto.

Eteneminen tallentuu selaimen muistiin, joten pelin voi jatkaa myöhemmin samalla laitteella. **Aloita alusta** -nappi tyhjentää tallennuksen.

## Muokkaus

Huoneet, oppitunnit ja tehtävät ovat `index.html`-tiedoston `ROOMS`-taulukossa. Vastaukset tarkistetaan kirjainkoosta ja välimerkeistä riippumatta; yhdelle lukolle voi antaa useita hyväksyttyjä vastauksia.
